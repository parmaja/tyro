# Space: Starfield & Universe Travel

A pseudo-3D starfield and universe travel experience for the Tyro Game Engine.
Hundreds of stars stream toward the viewer; steer through the void, boost into
warp, and watch nebula clouds, comets and planets drift by.

## How to Run

`
bin\tyro.exe games\space\space.tyro
`

## Controls

| Key / Input | Action |
|-------------|--------|
| **Mouse** / **WASD** / **Arrows** | Steer |
| **SPACE** | Boost (warp) |
| **SHIFT** | Slow cruise |
| **S** | Toggle glow shader |
| **R** | Reset voyage |
| **ESC** | Exit to desktop |
