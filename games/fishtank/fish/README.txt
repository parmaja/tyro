# Fantasy Pixel Cursors

Thanks for using Fantasy Pixel Cursors!

# Asset Info

* 220 individual sprites, each provided as a 32×32 px PNG file
* Transparent backgrounds


# Spritesheets

Production File: all_items_spritesheet_32x32.png

This is a tightly packed spritesheet intended for automatic slicing.

* Spritesheet size: 640×352 px
* Grid: 20 columns × 11 rows
* Cell size: 32×32 px
* Margin: 0 px
* Spacing: 0 px
* Total sprites: 220

 Slice the spritesheet using a fixed 32×32 px grid. Each sliced sprite will match its corresponding individual 32×32 px PNG image exactly.
For pixel-perfect rendering, use Point or Nearest Neighbor filtering and disable smoothing or interpolation.


Preview File: all_items_preview.png

The preview sheet is 1300×715 px and includes additional transparent spacing around each image for clearer presentation.

 It is intended only for browsing and previewing the full collection. Do not use the preview sheet for automatic slicing, as its cells include extra transparent space and will not match the individual 32×32 px PNG images.



# Cursor Hotspots

Most cursors are designed to work with Unity's standard (0, 0) hotspot — the top-left corner of the texture.



# AI & Manual Editing

AI image generation was used to create the initial artwork for this asset pack. The generated images were manually selected, reviewed, edited, and refined for the final asset.

If you notice a problem with a specific cursor — such as unwanted pixels, transparency issues, incorrect alignment, or any other visual issue — please contact me and I will fix it.
