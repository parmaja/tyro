# Make 5 Games with Tyro

[<< Tyro docs index](../../docs/README.md)

A short course for complete beginners. Each lesson is one small script that
grows from the previous one. Type the code yourself — changing a number and
pressing `F5` is how you learn.

| Lesson | Game | New idea |
|--------|------|----------|
| [1](01-drawing.md) | Dots and boxes | `update(dt)` / `draw()` and drawing |
| [2](02-moving.md) | Catch the dot | keyboard input and `dt` movement |
| [3](03-sprites.md) | Catch the stars | sprites, score and collision |
| [4](04-scenes.md) | Space catcher | scenes, pause, restart and sound |
| [5](05-juice.md) | Bubble pop | tweens, particles, save/load and export |

Before lesson 1, press `F8` in Tyro and type `new game`, then `F2` to edit and
`F5` to run. Press `F1` for shortcuts and `F9` for the in-window API cheat
sheet. Every script in this course needs no image files.
