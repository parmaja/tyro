# Extra gamepad mappings, SDL/GLFW format, one controller per line.
#
# Most pads (Xbox, PlayStation, ...) are already known to the engine's input
# library and need nothing here. Generic/no-name pads usually are not: without
# an entry every button and axis reads as released, even though Windows itself
# sees the controller fine. Adding a line makes it behave like an Xbox pad.
#
# Get the GUID from the tool that prints "GLFW: ..." or from SDL's database.
# Format: <GUID>,<name>,<controls>

# GAME BOX JOYSTICK (VID_20BC PID_5560), a Betop-family pad.
# The two GUID forms below cover both ways GLFW can derive a Windows pad's id;
# only the one that matches is used, the other line is simply ignored.
